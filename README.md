# SelfEvolution Frontend

SPA em **React 19** + **Vite** + **React Router**, com Tailwind CSS 3.

## Setup rápido

```bash
npm install
cp .env.example .env.local
npm run dev
```

O app sobe em `http://localhost:3000`. A API Core continua em `http://localhost:8080` (`VITE_API_URL`).

Documentação em [`docs/`](./docs/) — comece por `system-design.md`, `fluxo-paginas.md` e `processo-desenvolvimento.md`.
